# System Interactions

Exercises that interact with the operating system using system-level libraries
like `fcntl.h` and `unistd.h`.

## Topics

- File descriptors and low-level file I/O
- System calls (`open`, `read`, `write`, `close`)
- File control operations

## Notes

These exercises are recommended on **Linux** or Unix-like systems.

They are not necessarily harder than previous sections
